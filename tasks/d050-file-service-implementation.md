## Configuration / lifecycle

LocalFileService(policies:tuple[AgentPolicy,...]) builds PolicyTable and persistent grant-specific LocalAdapter/LocalWriter pairs keyed by(agent_id,source_alias); source_id on each adapter=grant.alias, root=grant.root, max_read_bytes=grant.max_read_bytes, writer cap=grant.max_write_bytes, max_list_entries=2000. Limit service to <=6 configured agents / <=32 total grants; reject oversize config before opening adapters. Roots must already exist and satisfy adapter's no-follow constructor; never create configured roots or fall back to broader roots. If startup fails, close already-opened adapters once, preserve original exception. No request accepts host roots; two agents' identical aliases never share the wrong root.

Operations synchronous; no unbounded queue, threadpool or hard syscall-cancellation promise. They can run concurrently on retained adapters. Borrow an adapter lease under a short condition lock; never hold that lock during I/O. Count active leases until the actual operation returns. close(*,timeout=5.0)->bool stops new leases, waits at most timeout for active operations, returnsFalse with resources still open if not drained; a later close can finish. ReturnTrue only after all adapters closed once. Concurrent close callers must not double-close; no close/reuse of active descriptors. Non-daemon caller threads may prevent process exit; do not promise bounded process termination. Operations after drain starts raise ServiceError unavailable. Constructor/close are lifecycle methods, not agent tools. No __del__ forced closure of active operations.

ServiceError(Exception) has fixed code from invalid/denied/not_found/exists/too_large/busy/unavailable/timeout, outcome_uncertain:bool,retry_safe:bool; safe static message/repr, never raw OS errors, tokens/roots or file bytes. Expose __cause__ only if it cannot carry secrets? Prefer raise safe error from None at service boundary. Don't leak underlying exception via automatic traceback context in rendered error text; code-only HTTP errors later. No audit/logging scope here.

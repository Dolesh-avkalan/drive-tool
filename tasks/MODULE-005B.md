## Exact behavior

- Same source/state/ref checking, root/directory/special-entry rejection, canonical p/ IDs, anchored O_NOFOLLOW traversal and error taxonomy as read_bytes. A narrow shared private regular-file opening/ownership helper is allowed if needed; keep old read_bytes behavior unchanged and prove it. No pathname reopen after descriptor resolution. Per-call descriptors support concurrent reads; adapter.close racing calls remains unsupported.
- offset must be a non-bool int in [0,2**63-1]. Explicit length must be a non-bool int in [1,self.max_read_bytes]. None selects min(262144,self.max_read_bytes). Reject offset+effective_length >2**63-1 with ValueError. Non-int/bool values TypeError; out-of-range int ValueError. Invalid options must fail before opening/traversing/stat/read syscalls for this operation (source/state checks may retain existing precedence). Constructor's byte cap is already positive; use its actual internal/property name.
- max_read_bytes is the maximum requested/returned bytes PER RANGE CALL; a larger total file is permitted. read_bytes continues rejecting whole files larger than its cap. Do not load/read/discard the prefix, call read_bytes then slice, mmap the file, or allocate from total file size.
- Require callable os.pread for this capability; otherwise read_range raises UnsupportedPlatformError before filesystem access, without breaking existing LocalAdapter construction/read_bytes on a platform that otherwise satisfies their contract. Add _os_pread(self,fd,length,offset) seam. No lseek shared-offset fallback and no weakened no-follow fallback.
- Open the target once through anchored traversal; fstat that opened descriptor, validate regular file before reading. observed_size and observed_mtime_ns come from this initial fstat only. They are observations, never a coherent snapshot/version/content-hash promise. Do not reject offset beyond observed_size: pread naturally yields empty bytes, and concurrent growth may make data available.
- Loop pread in chunks at most65536 and remaining requested bytes, with offset+bytes_collected; handle short nonempty reads by continuing, EINTR by retrying. Total successfully returned syscall bytes <= effective_length. No lookahead/probe past this window. Never issue a zero-length pread.
- eof_observed=True ONLY when a pread inside the requested budget returns b''; otherwise False. A result that exactly fills the requested window has eof_observed=False even when initial metadata size says it ends at EOF. Empty/offset-beyond-EOF usually returns b''/True; truncation/growth may change this. Do not derive EOF from stale initial fstat or a short nonempty read. Repeated calls can see different versions; no snapshot/cursor/eventual-consistency guarantee.
- Preserve OSError causes as LocalStorageError, primary exception priority during cleanup, every acquired fd closed exactly once, no retry of ambiguous close, and no partial successful return on read/fstat/cleanup error. No global lock/new hard syscall-deadline claim. KeyboardInterrupt/programming errors must not become partial successes. Infinite repeated EINTR/blocked kernel I/O is not hard-cancelled by this adapter.
